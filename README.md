# 📚 Smart Assignment Submission System

A web-based application that simplifies assignment submission and management for educational institutions. Students can securely upload assignments, while administrators can create, manage, and review submissions through an intuitive dashboard.

## 🚀 Features

- 👨‍🎓 Student Registration & Login
- 🔐 Secure User Authentication
- 📤 Assignment Upload
- 📋 View Assignment Status
- 👨‍💼 Admin Dashboard
- 📝 Create & Manage Assignments
- 📅 Assignment Deadline Management
- 📊 Student Submission Reports
- 📱 Responsive Design

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP (Apache)

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Ptlmohit/smart-assignment-submission-system.git
```

2. Move the project to the `htdocs` folder.

3. Start **Apache** and **MySQL** using XAMPP.

4. Import the database:

```
database/sass_db.sql
```

5. Open your browser and visit:

```
http://localhost/smart-assignment-submission-system
```

## ▶️ Running the Project with XAMPP

### Prerequisites
- XAMPP (Apache & MySQL)
- PHP 8.x
- MySQL
- Web Browser

### Steps

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Ptlmohit/smart-assignment-submission-system.git
   ```

2. Move the project folder to:
   ```
   C:\xampp\htdocs\
   ```

3. Open **XAMPP Control Panel** and start:
   - Apache
   - MySQL

4. Import the database:
   - Open `http://localhost/phpmyadmin`
   - Create a database (if needed).
   - Import:
     ```
     database/sass_db.sql
     ```

5. Open the project in your browser:
   ```
   http://localhost/smart-assignment-submission-system/
   ```
